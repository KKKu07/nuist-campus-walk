# 阶段总结 v0.5（截至 2026-11-28 晚）

> 新主会话的交接文件。细节记录见 `docs/progress-v0.4.md`、`docs/progress-v0.5.md`（含各子会话小节）、`docs/plan-v0.5.md`、`docs/zones.md`、`data/dorms/dorms.csv`、`data/blender/README.md`、`docs/gameplay-phone.md`。

## 已做好的（可以讲给组员）

- **全校 1:1 场景**：约 320 栋楼（64 个 Blender 精修地标/宿舍模型 + 约 180 栋 Blender 普通楼 + 少量程序楼），303 条路，6 片水域，约 3.3 万棵树。
- **数据有据可查**：位置以项目无人机航拍为准（三维重建实测 119 栋楼高）；官网三维地图（map.nuist.edu.cn）用于楼名、路名、楼型、屋顶色、地面材质，已按区配准（偏东约 15 m 的系统误差已校正）；关键处有学校新闻照片。
- **宿舍群**：校内 65 栋逐栋核对（官网层数、屋顶、塔楼）并建模（文园 21、沁园 23、东苑 21）。
- **道路**：41 条逐条核对宽度/人行道/中心线；官网路名 + 路名牌；按车道数画标线；人行道白色瓷砖；路缘、路口斑马线；盘城新街下穿通道（正气路桥洞、文通地下通道 + 机动车隧道）。
- **地面**：0.5 m 地面材质图（草坪/灰石/瓷砖/红砖/沥青/水/球场），楼顶干净屋面 + 官网屋顶色；三个田径场（中苑主席台按学校照片）、球场、气象观测基地（观测场 + 站房）、西苑文创街区、长望街区。
- **植被与设施**：行道树按航拍排布、树冠补种、叶片树冠、绿篱、灌木、庭院灯/路灯（夜景光斑）、长椅、垃圾桶、停车位、围栏 + 空气墙、碰撞。
- **玩法**（游戏交互会话）：Tab 手机（消息、扫码骑 7ma、刷码坐公交、钱包、相机）、取快递/带饭等兼职任务、食堂点菜、开场选角色、云游导览（Y）、12 站打卡、夜景（T）。
- **工程**：GitHub 私有备份 Gangtiedaguanzi/nuist-campus-3d；同学仓库 KKKu07/nuist-campus-walk 有旧分支 yunyou-nuist（带玩法，待删）；展示页 `web/showcase.html`（无玩法，供老师看）已在本地做好。
