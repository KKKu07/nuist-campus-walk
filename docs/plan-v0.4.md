# v0.4 精细化计划（目标：超越《网上南宁》的还原度）

用户要求（2026-11-28）：一栋一栋楼、一条一条路、一块一块区域，全部和**学校官网地图**、**项目航拍**、素材照片对照确认；地面要有真实材质，操场要做出来，树要换掉，主干道要宽、不能有树；保证可玩性。地标精修模型（Blender 会话）出来后再替换。

## 参照依据（按可信度）

1. 航拍正射图（`全景航拍.jpg`，2025，已对齐）+ 航拍三维重建 DSM（`data/raw/dsm.npy`，楼高、树高）。
2. 学校官网地图（`data/official/`：点位、官方楼名、公交线、手绘瓦片 + 坐标换算）。
3. 楼宇实拍照片（`data/source/航拍/`）。
4. OpenStreetMap（轮廓、道路中线、运动场多边形）。

## 工作包

### WP1 地表分类图（ground truth）
- 用正射图 + DSM + OSM 生成 1 m 分辨率地表分类：草地、树冠、铺装广场、沥青路面、水面、塑胶跑道、人造草坪、球场（篮球/网球彩色地坪）、裸土、建筑。
- 产出 `web/public/campus/landcover.png`（每像素一个类别）+ 检查图。
- 游戏地面着色改为“按类别贴真实材质”，航拍只作远处色调；近处不再糊。

### WP2 道路
- 沿 OSM 中线做横截面，在正射图上实测路面宽度（灰色低饱和像素连续段），中位数作为该路宽度；主干道按实测（含中央绿化带则拆成双幅）。
- 路面范围内禁止生成树；行道树改为沿路边规则排布（间距约 7 m），只在航拍上路边确有树冠的路段。
- 路口：交叉处补路口铺面，标线在路口断开；人行横道；路沿石带高差。

### WP3 运动场
- 跑道：OSM `leisure=track` 多边形拟合 400 m 标准跑道（直道 + 半圆），红色塑胶 + 白色分道线；内场人造草坪 + 足球场标线 + 球门。
- 球场：OSM `leisure=pitch`（篮球/网球/排球）按外接矩形铺彩色地坪 + 标线 + 篮架/球网 + 围网。
- 与官网“体育场馆”点位逐个对照名称。

### WP4 植被
- 单株识别：DSM 高度（地物高 2–25 m 且非建筑）+ 正射绿度 → 局部极大值 = 树中心，树冠半径来自高度/冠幅。
- 树种：主干道行道树（法桐/香樟，大冠）、银杏（秋季黄）、樱花（樱花大道）、松柏（山上）、灌木绿篱；新树模型（分层树冠、平滑着色、多色），保持实例化性能。
- 草地：近处草丛实例（只在镜头附近生成）。

### WP5 建筑逐栋核对
- 生成核对表 `docs/building-audit.csv`：每栋楼的官方名、OSM 名、高度来源（实测/照片/估算）、官网点位是否落在轮廓内、立面风格、颜色来源。
- 修正：名字冲突、官网有但缺失的楼、轮廓偏移、明显错误的高度；楼的入口（朝最近道路一侧加门厅/雨棚）、底层勒脚、楼名牌。
- 地标楼等待 Blender GLB 替换。

### WP6 可玩性
- “云游打卡”任务：12 个地标打卡点（图书馆、气象楼、逸夫楼钟楼、老校门、东大门、临江楼……），到达自动盖章，进度面板，集齐解锁明信片。
- 新手引导、公交到站提示、地图图例。

### WP7 集成与验收
- 接入 Blender 会话的地标 GLB（`data/blender/models.json`）。
- 全校巡检截图（每个片区地面视角 + 俯视），性能检查（桌面 ≥ 60 FPS，手机降级），打包。

## 执行顺序
WP1 → WP2 → WP3 → WP4 → WP5 → WP6 → WP7。每完成一个工作包，在 `docs/progress-v0.4.md` 记录产出、核对结果和遗留问题。
